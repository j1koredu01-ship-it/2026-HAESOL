깃허브(GitHub Pages) 3분 배포 방법

이 파일(index.html) 하나만 깃허브에 올리면, 14개 반 선생님들이 스마트폰이나 교실 컴퓨터로 접속 가능한 공식 웹사이트 주소가 무료로 즉시 생성됩니다.

  1. GitHub.com 로그인 후 우측 상단 [New repository] 클릭
  2. Repository name에 haesol2-endterm 입력, Public 체크 후 생성
  3. uploading an existing file 링크로 이 index.html 파일 업로드 & 저장
  4. 저장소 상단 Settings → 좌측 Pages 메뉴 클릭
  5. Branch에서 main 선택 후 Save 클릭
  6. 1~2분 뒤 나타나는 웹사이트 주소를 교내 메신저에 공유하시면 끝납니다!
